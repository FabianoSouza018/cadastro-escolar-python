# Cadastro Escolar

Programa desenvolvido em **Python** para realizar o cadastro simples de alunos.

O programa permite informar a matrícula, o nome e, opcionalmente, o curso do aluno. Também permite realizar vários cadastros em sequência.

## 🛠️ Tecnologias utilizadas

- Python

## 📌 Funcionalidades

- Cadastro de matrícula;
- Cadastro do nome do aluno;
- Cadastro opcional do curso;
- Exibição do resumo do cadastro;
- Possibilidade de cadastrar outro aluno.

## 📚 Conceitos utilizados

- Classe;
- Variáveis;
- Entrada de dados com `input()`;
- Estrutura condicional `if/else`;
- Estrutura de repetição `while`;
- Operadores lógicos.
